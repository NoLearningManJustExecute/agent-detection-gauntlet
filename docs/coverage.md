## Limitations

- **Pooled recall sets a high bar for a single rule.** The denominator holds every succeeded attack of every class, and rules are built for one mechanism each. That is the registered reading, applied as written.
- **Small populations.** A column flagged small-N rests on a handful of traces in few classes. Its verdicts use the same bar and are reported as measured. Read the interval and the per-class table beside them.
- **The class map is an input, not a measurement.** It comes from the source threat model at commit `c67352a45ac23a1b833242459a15f0723ed933fc` and was keyed into this repository's vocabulary for this phase, after results were seen. It can only remove a verdict, never grant one, but it decides which reason a technique shows and which counts it gets.
- **The reason depends on how the source files a class.** It files tool-description attacks under IDs this catalog lacks, while the rules here map tool-metadata text to indirect injection. An attack variant counts under the class whose objective it pursues, not the technique its delivery uses. So a technique shown with no successful attacks can still have rules firing on related attacks. The source also ties obfuscated variants to AML.T0068, which no rule here maps to and the class map does not hold.
- **Two OWASP LLM numberings.** This repository's catalog and the source threat model both say 2026 but number OWASP LLM differently: the source, which records checking its IDs against OWASP, has LLM03 as Excessive Agency and LLM06 as Unbounded Consumption. The class map matches by title, so read each LLM row here by the title beside it, not by number. Rule files are frozen and keep their IDs. Phase 7 checks every ID against the primary source.
- **Framework mappings are unverified** until Phase 7. A rule's mapping is its author's claim about the technique it detects, and coverage inherits that claim.
- **Single model and single-author corpus**, as in the baseline and evasion reports.
